# Player instructions — proposed controls

> **Pre-production only.** These describe the intended v0.1.0 fighting game. The current site is a teaser and does not implement them.

| Action | Player 1 proposed key | Player 2 proposed key |
| --- | --- | --- |
| Left / right | A / D | Left / Right arrows |
| Jump | W | Up arrow |
| Crouch | S | Down arrow |
| Light attack | F | J |
| Heavy attack | G | K |
| Block | H | L |
| Psyche-out | R | I |
| Pause | Esc | Esc |

Subject to rebind, layout/accessibility review, focus management and keyboard ghosting tests. Gameplay must not seize browser or operating-system input beyond normal gameplay focus. Psyche-outs may alter in-match states only.

A match should clearly display player health, time remaining, rounds, special-meter availability and KO/draw outcomes. Character-specific inputs must be discoverable from within the game.
